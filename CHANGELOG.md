# Changelog

All notable changes to Tadabbur are documented here. Releases follow Semantic Versioning and use tags without a `v` prefix, as required by Obsidian.

## [0.2.0] - 2026-09-04

### Added

- Reflection actions for Falah's verse menus, rendered Quran references, and reference detail view.
- `/reflect` workflow for inserting a Quran reflection at the current editor position.
- Incremental reflection-index updates for file creation, modification, rename, and deletion.
- Arabic localization coverage and regression tests for reflection actions and services.

### Changed

- Requires Falah plugin API v7 or newer.
- Updated documentation, package metadata, and release automation for the 0.2.0 release.
